How this works

What counts as slop
  • Genuine — names a concrete action on a concrete target, so someone could pick it up and do it: “Renew the passport”, “Fix the leaking tap”.
  • Slop — keyboard mash, or filler that names no target: “asdfghjkl”, “do something”, “align stakeholders”.
  • Being unethical is not the same as being slop. “Steal someone's wallet” is a clear instruction, so it is genuine text.
How the model scores

Each word gets a learned vector. A text is encoded by averaging the vectors of its words, and a logistic regression turns that average into a score from 0 (genuine) to 1 (slop).

Because the encoding averages words, word order is lost — “buy milk” and “milk buy” score the same. Words the model never saw in training collapse to a single <UNK> vector, which is why the coverage figures matter.

Where the numbers come from

Training, evaluation and scoring all use the subsystem code in subsystems/ — the same files the test page and the experiments use. train.mjs trains the shipped model.json from training.json on the command line; this page trains the very same model in your browser.
